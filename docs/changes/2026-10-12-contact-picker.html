变更说明：添加从通讯录选择号码功能

日期：2026-10-12 · 性质：功能增强

一、为什么做

之前添加号码只能手动输入，如果骚扰电话恰好存在通讯录里（比如之前联系过的商家、快递）， 还要自己翻通讯录找到号码再复制过来，不方便。

二、改了什么

  • 新增 MobileBlack/ContactPicker.swift：用 UIViewControllerRepresentable 包装系统 CNContactPickerViewController，让 SwiftUI 界面能调起通讯录选人。
  • 修改 MobileBlack/AddNumberSheet.swift：在号码输入框下方增加「从通讯录选择」按钮，选中联系人后号码自动填入输入框，联系人姓名自动填入标签字段。
  • 修改 MobileBlack.xcodeproj/project.pbxproj：Debug 和 Release 两个配置均加入 INFOPLIST_KEY_NSContactsUsageDescription，系统会在首次调起通讯录时弹出权限请求。
  • 更新 README.md：「怎么用」部分补充通讯录选号说明。

三、设计要点

  • 使用 contactPicker(_:didSelect:) delegate 而非 property-based 模式——系统只返回用户选中的那个号码，App 不需要也不应该读取通讯录全量数据，权限更小。
  • predicateForEnablingContact 设为 phoneNumbers.@count > 0，无电话号码的联系人置灰不可选。
  • 纯加性改动：手动输入号码的原有流程完全不受影响。

四、影响范围

仅主 App target（MobileBlack），Call Directory 扩展不受影响。 编译验证通过（零错误零警告），31 条单元测试全绿。
